# G1-016, the conformal boundary of anti-de Sitter space: source reading

## Source read (19 November 2026)

M. Blau, *Lecture Notes on General Relativity*, version "Last update November 15, 2026",
http://www.blau.itp.unibe.ch/newlecturesGR.pdf, read in the PDF (printed page = PDF page − 1):

* p. 927: (39.76) the global metric `ds² = −(1 + r²) dτ² + (1 + r²)⁻¹ dr² + r² dΩ²`, `r = sinh ρ`.
* pp. 927–928, section 39.3.2: (39.79)–(39.83) the conformal radial coordinate, `cosh ρ = 1/cos θ`, `sinh ρ = tan θ`,
  `θ ∈ [0, π/2)`; (39.84) `ds² = cos⁻² θ (−dτ² + dθ² + sin² θ dΩ²)`.
* p. 929: (39.85) "AdS is conformal to one half of the Einstein static universe", `0 ≤ θ < π/2`; the conformal boundary
  `θ = π/2`, "timelike", (39.86) `ds̃²|_{θ=π/2} = −dτ² + dΩ²`, (39.87) topology `S² × ℝ`.

## Statements (`Lightlike/Spacetime/AdSCompactification.lean`)

* `ads_eq_conformal_esu`: (39.84) from (39.76) with `r = tan θ` (`dr = dθ / cos² θ`, `1 + tan² θ = cos⁻² θ`), for a tangent
  vector `a ∂_τ + b ∂_θ + w`, `q = dΩ²(w, w)`.
* `bijOn_tan_ads`: `θ ∈ [0, π/2) ↦ r = tan θ ∈ [0, ∞)` is a bijection.
* `cos_eq_zero_ads_boundary`, `ads_boundary_metric`: on `[0, π/2]` the conformal factor vanishes exactly at `θ = π/2`,
  and there the conformal metric restricted to the boundary is `−dτ² + dΩ²`.

Differences:
* representation: the statements are for the radial part with the sphere factor through `q = dΩ²(w, w)`, starting from
  the `r`-form (39.76) of the global metric (the source passes through `ρ`); "timelike" is the form `−dτ² + dΩ²` of the
  boundary metric.
