# 1.13.1 have no wheels for 3.13 or later, and no numpy release has wheels for both 3.9 and 3.13,
# so 3.13 and 3.14 get newer versions (the markers below); 3.9 to 3.12 keep the older ones.
# Install with
#   python3 -m venv .venv && . .venv/bin/activate && pip install -r requirements.txt
# and, in that environment, run the cross-checks with  python3 scripts/run_python_checks.py --all
# The checks pass with these versions on Python 3.12 (as in CI and Codespaces), on 3.9, and on
# 3.13 and 3.14; every package has wheels for Linux and macOS on all four.
