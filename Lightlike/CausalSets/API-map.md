# Causal sets

## Abstract (Alpha)

This API is a bridge between Lorentzian geometry and causal sets. It defines causal sets as locally finite partial orders with their links, chains, antichains and intervals, turns the causal order of Minkowski space into such a partial order, and sprinkles uniform points into a causal diamond. It proves that `n` uniform points of any region have `n (n - 1) p` related pairs in expectation, with `p` the probability that two uniform points are related, and that `p = 1/4` in `1 + 1` dimensions and, in every dimension, the Myrheim–Meyer value `p = Γ(D+1) Γ(D/2) / (4 Γ(3D/2))`, `D = d + 1`, so `1/20` in `3 + 1` dimensions. It also shows that a `1 × 2` rectangle instead of the diamond gives `7/48`, not `1/4`. The Poisson form of the sprinkling is open.

## Content (Alpha)

A causal set is a partial order in which every interval is finite; a link is a covering relation, and every strict relation is a finite chain of links, so the order is generated by its links [1] {1}. The causal order of Minkowski space `ℝ^{d+1}` is the closed future light cone; it is a partial order, so any finite set of points of Minkowski space is a causal set with the induced order [2] {2}. This cone is the causal future of the Lorentzian interface (`Causal.minkowski_causalFuture_eq` of the causal-structure area, where it is proved), used here directly.

A sprinkling is a sample of independent uniform points. For a region of finite positive volume, `n` points have `n (n - 1) p` pairs `x ≺ y` in expectation, with `p` the probability that two uniform points are related; this uses a fixed number of points and no Poisson process [3] {2}. In the causal diamond of `ℝ^{1+1}`, light-cone coordinates turn the diamond into a square and the order into the coordinatewise order, and `p = 1/4`, so `n (n - 1) / 4` relations in expectation [4] {2}. In every dimension `d + 1` with `d ≥ 1` the volume of a causal interval is the volume of the unit diamond times the power `d + 1` of the proper time, by a Lorentz boost that preserves the form, the cone and Lebesgue measure [6] {2}; integrating over the diamond with the radial formula and the real Beta integral gives the Myrheim–Meyer value in every dimension [7] {2}, and `p = 1/20` in `3 + 1` dimensions [8] {2}. The Beta integral for real exponents, `∫₀¹ s^(a-1)(1-s)^(b-1) = Γ(a)Γ(b)/Γ(a+b)`, is proved from Mathlib's complex form [9] {2}. A wrong-model check: uniform points of the rectangle of time extent `1` and space extent `2` are related with probability `7/48`, so the count depends on the region [5] {2}.
